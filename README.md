# Meu primeiro repositório

Este é o meu primeiro projeto utilizando Git.

## Como verificar a versão do Git

```bash
git --version
```
## Como listar os arquivos da pasta

Para listar os arquivos e as pastas no PowerShell, utilize:

```powershell
Get-ChildItem
```

Também é possível utilizar a forma abreviada:

```powershell
dir
```

Para mostrar arquivos e pastas ocultos, como `.git` e `.github`, utilize:

```powershell
Get-ChildItem -Force
```
